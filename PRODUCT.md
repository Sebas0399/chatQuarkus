# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Business owners, operations managers, and client service teams using ChatQuarkus for customer engagement and assistant management.

## Product Purpose

Provide a unified, high-performance CRM, real-time messaging platform, and AI assistant management console embedded directly within a Quarkus backend via Quinoa.

## Positioning

Combines high-speed Quarkus backend execution with an integrated Angular 16 frontend and GraalVM-powered assistant script testing.

## Operating Context

Daily operations involving customer chat threads, contact directory management, company registration, and assistant tool configuration.

## Capabilities and Constraints

- REST APIs secured with JWT authentication.
- Angular 16 SPA bundled via Quarkus Quinoa.
- PrimeNG and Tailwind CSS UI components.
- GraalVM JavaScript engine integration for assistant tools.

## Brand Commitments

Clean, professional, and accessible business UI utilizing modern layout principles.

## Evidence on Hand

Working Quarkus backend with Panache persistence and fully integrated Angular SPA frontend.

## Product Principles

1. **Performance First:** Zero separate frontend deployment overhead via Quarkus Quinoa embedding.
2. **Operational Clarity:** Focused, scannable dashboards and chat interfaces.
3. **Robust Security:** JWT-authenticated endpoints and protected routing.

## Accessibility & Inclusion

Standard web accessibility best practices with high-contrast text and clear form controls.
